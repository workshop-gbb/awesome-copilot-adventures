# C# legacy solutions

These reference implementations support the preserved version-one coding challenges.

## Prerequisite

[.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)

## Build

```bash
dotnet build CopilotAdventures.sln
```

## Run

```bash
dotnet run --project CopilotAdventures.csproj -- tempora
```

Available names: `algora`, `chamberofechoes`, `eldoria`, `lumoria`, `mythos`, `mythos-test`, `stonevale`, and `tempora`.
