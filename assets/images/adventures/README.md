# Adventure covers and concept illustrations

The 14 current adventures now use generated WebP covers supplied by the maintainer.
Each lesson also keeps its original monochrome SVG in an expandable concept view,
including localized titles and descriptions. The professional hands-on track is unchanged.

Prepared on 2026-09-08: the 2752 x 1536 JPEG originals were center-cropped and
downscaled to 1456 x 832 WebP covers, without stretching. All original files remain
unchanged. [The media inventory](../../adventure-media.json) records the mapping.
The covers appear in lessons, the adventure catalog and library cards; adventure
learner kits include both the optimized cover and the original SVG.

These are visual stories, not product screenshots, technical diagrams or evidence
that an agent ran. Some generated scenes contain decorative lettering; commands,
titles and essential explanations remain in the localized lesson text. Preserve
the original provenance rather than presenting generated art as a real interface.
The [media briefs](../../../docs/media-prompts.md) describe the intended concepts.

The supplied MP4s are multi-adventure montages, not recordings of individual labs.
Their original files remain here; the [video notes](../../video/README.md) describe
the silent playback copies and reduced-motion behavior.

## Review checklist

- [ ] The illustration matches the concept and the consuming lesson's alternative text.
- [ ] It remains legible at desktop and narrow reading widths.
- [ ] The SVG has a viewBox, title and description, with no remote resource or script.
- [ ] Meaning is not conveyed by color alone.
- [ ] Updated media is included when regenerating [learner kits](../../../docs/downloads.md).
