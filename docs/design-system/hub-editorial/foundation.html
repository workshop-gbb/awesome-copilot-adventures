05 / Reutilização

Uma base para copiar.
Não uma dependência.

O template usa HTML, CSS e JavaScript sem framework. As fontes são locais. Copie a pasta inteira, preserve as licenças e substitua conteúdo e identidade.

Comece pelo template

  1. Duplique starter.html e abra a cópia no navegador.
  2. Mantenha tokens.css, components.css, hub.js e a pasta fonts/ nos caminhos relativos indicados.
  3. Troque o nome do projeto, os textos e os destinos dos links. Não copie métricas, fotos ou marcas de terceiros.
  4. Ajuste os tokens sem remover os estados de foco, erro e tema escuro.

Contrato mínimo de uma página

<html lang="pt-BR" data-he-theme="light">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <title>Meu projeto</title>
    <link rel="stylesheet" href="./tokens.css">
    <link rel="stylesheet" href="./components.css">
    <script src="./hub.js" defer></script>
  </head>
  <body class="he">
    <main>
      <section class="he-section">
        <div class="he-container">
          <h1 class="he-section__title">Meu projeto</h1>
        </div>
      </section>
    </main>
  </body>
</html>
