# Hands-on instructions

Use the [catalog](../index.md) to select one exercise and its local fixture.

- `Labs/`: numbered preparation and exercise guides.
- `Reference/`: shared environment, current product guidance and audit evidence.
- `Concepts/`: scoping and PRD examples.
- `Labs/Media/`: historical source screenshots, not current UI requirements.

The root site publishes this track at `/hands-on/`. Follow the selected guide's
permalink rather than old nested `index.html` URLs.
