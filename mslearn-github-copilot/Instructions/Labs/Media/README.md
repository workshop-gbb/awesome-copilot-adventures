# Historical screenshot provenance

These images came with the imported training material. They show historical editor
layouts, model names, settings and simulated test runs. They are retained for
attribution/reference, not as authoritative current setup instructions.

The integrated guides do not require these screenshots. Use the current official
sources and Command Palette rather than a button location or a displayed test count.
Do not present the images as evidence of a learner's own run.

In particular, Microsoft Copilot in a browser is not GitHub Copilot in VS Code;
an old Ask/Edit/Agent selector does not define the current role/harness model.
